# ⚔ ศึกอารีน่า (Battle Arena)

เกมยิงต่อสู้แบบ top-down สำหรับ **2-4 คน บนคีย์บอร์ดเดียวกัน** — ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไรเลย

> โปรเจกต์นี้แยกขาดจากแอป stock-auto-analyzer โดยสิ้นเชิง ไม่มีการแชร์โค้ดหรือ dependency ใดๆ

## วิธีเล่น

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ แล้วเลือกโหมดจากเมนู (แตะ/คลิก หรือกดเลข):

- 🤖 **1 คน ปะทะบอท**
- 👥 **2 คน จอเดียวกัน** (มือถือ = แบ่งจอซ้าย-ขวา, คอม = แชร์คีย์บอร์ด)
- ⚔ **2 คน + บอท 2 ตัว**
- 🌐 **ออนไลน์ข้ามเครื่อง 2-4 คน** — เล่นกับเพื่อนไกลๆ ได้ทั่วประเทศ
- คีย์บอร์ดกดเลข `3` / `4` เล่น 3-4 คนบนคอมได้

### 🌐 เล่นออนไลน์กับเพื่อนทางไกล

1. ทุกคนเปิดไฟล์เกมในเบราว์เซอร์ของตัวเอง (ต้องต่ออินเทอร์เน็ต)
2. คนนึงกด **"สร้างห้องออนไลน์"** จะได้รหัสห้อง 5 ตัว เช่น `KQ7XF`
3. ส่งรหัสให้เพื่อนทาง LINE/แชต แล้วเพื่อนกด **"เข้าห้องเพื่อน (ใส่รหัส)"**
4. เข้าได้สูงสุด 4 คน พอครบแล้วโฮสต์กด **เริ่มเกม** — จบแมตช์แล้วรีแมตช์ต่อได้เลยไม่ต้องตั้งห้องใหม่

> เทคนิคเบื้องหลัง: เชื่อมต่อแบบ P2P ด้วย WebRTC (PeerJS) เครื่องโฮสต์เป็นคนรันเกม
> ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง ใช้ได้ทั้งมือถือและคอมผสมกันในห้องเดียว
> หมายเหตุ: เน็ตบางเครือข่าย (เน็ตองค์กร/CGNAT บางเจ้า) อาจเชื่อม P2P ไม่ได้

### 📱 บนมือถือ / แท็บเล็ต (หมุนจอแนวนอน)

- **ลากนิ้วในฝั่งของตัวเอง** = จอยเสมือน เดิน + เล็งไปทางที่เดิน
- **ยิงอัตโนมัติ** ไม่ต้องกดปุ่มยิง
- **ปุ่ม ⚡ มุมล่าง** = พุ่งหลบ (มีวงแหวน cooldown รอบปุ่ม)
- เล่น 2 คน: คนนึงถือฝั่งซ้าย อีกคนถือฝั่งขวาของเครื่อง

## กติกา

- ยิงโดน -18 HP ทุกคนมี 100 HP — คนสุดท้ายที่รอดชนะรอบนั้น
- **ชนะครบ 5 รอบก่อน = แชมป์** 👑
- กระสุนสะท้อนกำแพงได้ 1 ครั้ง — ยิงอ้อมมุมเก็บเพื่อนได้
- Dash ใช้พุ่งหลบกระสุน มี cooldown (ดูวงแหวนรอบตัว)
- ฉาก/สิ่งกีดขวางสุ่มใหม่ทุกรอบ

## ไอเทม (สุ่มเกิดกลางสนาม)

| ไอคอน | ไอเทม | ผล |
|---|---|---|
| ⋔ | ยิงสามทาง | กระสุนแตกเป็น 3 ทิศ |

## เทคนิคเทพๆ

- เก็บโล่ไว้ก่อนแล้วค่อยบุก — แลกหมัดได้เปรียบเสมอ
- ยิงสะท้อนกำแพงใส่คนที่หลบหลังที่กำบัง
- Dash ทะลุดงกระสุนเข้าไปเก็บฮีลกลางสนาม
- ยิงสามทาง + กระสุนยักษ์ พร้อมกัน = โหดสุดในเกม
